## pangolin config reset

Make an organization use the global config again

### Synopsis

Remove the values set for an organization (the selected one by default), so it uses the global config again.

```
pangolin config reset [flags]
```

### Options

```
  -h, --help         help for reset
      --org string   Organization to reset (default: selected organization)
```
